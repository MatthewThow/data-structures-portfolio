[MatthewThow_CFBproject.ipynb](https://github.com/user-attachments/files/32177253/MatthewThow_CFBproject.ipynb)# College Football Talent vs ATS Performance

## Research Question

Is greater team talent associated with better against-the-spread performance
in college football?

## Data

The project uses CollegeFootballData API data for 2025 team talent and
against-the-spread performance.

The main variables were:

- Team talent score
- ATS win percentage
- Average cover margin
- Conference
- Games played
